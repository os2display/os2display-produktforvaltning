# Rollelandskab

## Driftsleverandør
Hoster OS2Display-installationer for kommuner og andre myndigheder.

Opgaver:
- Holde sig ajour med nye versioner af produktet og opdatere kundernes miljø
- Konfiguration af kunders site ifht. SSO 
- Konfiguration af fallback billeder og andre indstillinger der skal tilpasses lokale forhold
- Hjælp til tema-tilpasning på skabeloner
- Hjælper kunder med at oprette sager i issue tracker
- First level support på anvendelsen af produktet
- Evt. Etablere testsite for kunder
- Evt. kursus/undervisning hos kunder der onboarder OS2Display


## Udviklingsleverandør
Bidrager med kode til OS2Display. Det kan være både features og fejlretninger. Det gælder både OS2Display kernen samt plugin-systemet (templates + datakilder).

Opgaver:
- Er i dialog med produktforvaltningen før en opgave påbegyndes
- Følger arbejdsgang beskrevet i CONTRIBUTING.md
- Overholder kvalitetskrav til leverance beskrevet i CONTRIBUTING.md


## Vedligeholdelsesleverandør
Laver core maintenece af produktet. Er kontraktligt 
Opgaver
- Release management
- Code Review af kode fra udviklingsleverandører
- Rådgivning af udviklingsleverandører
- Rådgivning af produktforvaltning
- Monitorere og rapportere sikkerhedsricici
- Monitorere og rapportere problemer vedr. licensforhold i depenedencies
- Monitorere og raapprtere maintanancebehov i dependencies i issues
- Udføre corrective maintanance af core på bestilling fra produktforvaltning
- Vedligeholde teknisk dokumentation relateret til core produktet


## Produktforvaltning
- Kontakt til medlemskommuner
- Facilitering af møder i koordinations- og styregruppe
- Afholdelse af informationsmøder og medlemsmøder
- Nyhedsbreve
- Dialog med leverandører
- Sagbehandling i Git Issue Tracker
- Støtte til kvalificering af issues
- Støtte til crowd funding
- Brugerrettet dokumentation
